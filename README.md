# Medaka DJ - 交換日記 + インフラ監視ダッシュボード

メダカ水槽の可視化と交換日記を組み合わせた、教育的なDjangoプロジェクトです。

## 機能

### 🐟 メダカ水槽ダッシュボード
- リアルタイムで泳ぐメダカのアニメーション
- クリックで餌やり（波紋効果付き）
- システムテレメトリ（CPU、メモリ、リクエスト数のチャート）

### 📝 交換日記（Ideasページ）
- 記事の投稿・閲覧（画像アップロード対応）
- 各記事へのコメント機能
- タグによる絞り込み検索
- 記事削除はスタッフのみ（確認画面付き）

### 🛍️ 商品リンク（URL自動取得機能）
- 商品URLを入力するだけで自動的に情報取得
- 画像、タイトル、説明を自動入力
- 画像は自サーバーに保存（プライバシー保護）
- 閲覧履歴が外部サイトに残らない

### 🏷️ タグ機能
- タグで記事を分類・検索
- タグフィルター（クリックで絞り込み）

## セットアップ

1. **依存関係のインストール**:
   ```bash
   pip install django pillow requests beautifulsoup4
   ```

2. **データベースのマイグレーション**:
   ```bash
   python manage.py migrate
   ```

3. **スーパーユーザーの作成**:
   ```bash
   python manage.py createsuperuser
   ```

4. **サーバー起動**:
   ```bash
   python manage.py runserver
   ```

## 使い方

### 管理画面
`http://127.0.0.1:8000/admin/` にアクセスして、記事や商品を管理できます。

### 商品情報の自動取得
1. 管理画面で「Products」→「追加」
2. **商品URL**を入力（例：GitHubリポジトリ、楽天、など）
3. 「URLから商品情報を自動取得する」にチェック
4. 保存すると、タイトル・説明・画像が自動入力されます

**注意**: Amazonは厳しいボット対策をしているため、自動取得が失敗することがあります。その場合は手動で情報を入力してください。

### ページ構成
- **Dashboard** (`/`): メダカ水槽とシステムメトリクス
- **Ideas** (`/ideas/`): 記事一覧（全コンテンツ表示）

## 技術スタック
- **Backend**: Django 5.2
- **Frontend**: TypeScript（水槽）+ Vanilla JS
- **Charts**: Chart.js
- **Styling**: Custom CSS（ダークモード）

## プライバシー配慮
商品情報は自動取得時にサーバーに保存されるため、サイト閲覧中は外部サイトに情報が送信されません。「購入する」ボタンをクリックしたときのみ、外部リンクに遷移します。
